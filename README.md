# printandpujara

Pujara Print N Pack website.

- `frontend/`: Next.js website. See [frontend setup](frontend/README.md).
- `backend/`: API and uploaded website assets. See [backend setup](backend/README.md).
- `backend/insert-flex-vinyl-machines.sql`: Adds the Flex and Vinyl machines using the included images.

Install dependencies in each application directory with `npm ci` and configure its environment before running it. Environment secrets, certificates, database dumps, dependencies and build output are excluded from Git.
